## 개요

보호 리소스는 호스트·경로 범위와 검증된 주체·HTTP 메서드를 묶습니다. 공개 라우트의 우선순위나 헤더/JSON 조건으로 보호 범위를 우회할 수 없습니다. 라우트를 비활성화해도 보호 범위는 유지됩니다. 제거하려면 먼저 기존 범위에서 `enforce=false`를 저장하고 이후 변경에서 삭제합니다. JWT 검증과 전용 workload mTLS는 별도 선택 기능으로 구현되어 있으며, workload 경로 변경 시 기존 응답 스트림은 종료됩니다. 이 URL 범위 권한 검사가 세션 폐기·영구 감사·중앙 fleet 권한까지 제공하지는 않습니다.
