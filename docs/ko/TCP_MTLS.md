# TCP 워크로드 mTLS

## 개요

TCP 리스너에서 mTLS를 종료하고, 검증된 인증서의 SPIFFE URI를 라우트별 허용 목록과 대조한 뒤에만 업스트림에 연결합니다. 기존 SNI 패스스루와 구분하며, CA가 유효해도 허용되지 않은 주체는 거부합니다. 설정·인증서·신뢰 루트·CRL 변경은 새 설정 발행 시 준비하고, 기존 인증 스트림은 세대 교체 또는 유효기간 만료를 감지하면 종료합니다. 활성 바인딩의 로컬 인증서·키·CA·CRL 파일은 메타데이터를 500ms마다 폴링하고 전체 내용을 5초마다 검증하므로, 파일 변경도 자동으로 반영합니다. 잘못되거나 변경된 클라이언트 CA/CRL은 기존 신뢰를 유지하지 않고 해당 바인딩의 admission과 기존 인증 스트림을 닫습니다. 이 기능은 플릿 전체 자료 배포, HTTP 주체 바인딩, 분산 폐기 및 영구 감사까지 제공하지 않습니다.
