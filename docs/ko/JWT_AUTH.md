## 개요

서명된 RFC 9068 접근 토큰을 로컬 JWKS 또는 HTTPS/OIDC로 얻은 공개 키로 검증합니다. 발급자·대상·토큰 종류·필수 클레임·시간·scope/group 권한을 검사하고, 리소스 정책에 검증된 JWT 주체를 연결할 수 있습니다. 키 조회 취소·장애·교체·만료와 암호 검증 용량 부족은 인증 없는 전달로 이어지지 않습니다. 긴 업로드·SSE·WebSocket에도 토큰 시간·서명 키·경로 세대 검사를 유지하고, JWT와 mTLS를 함께 쓸 때는 두 신원이 모두 유효해야 합니다. 설정으로 특정 `jti`와 발급 시점 이전 토큰을 차단할 수 있으며, 설정 변경은 해당 경로의 기존 스트림 전체를 종료합니다. OIDC 브라우저 로그인, 일반 ID 토큰 수용, 발급자 로그아웃의 자동 연동, 재사용 차단, 영구 감사까지 구현했다는 의미는 아닙니다.
