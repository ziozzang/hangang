# 활성화와 비활성화

[문서 목차](../README.ko.md) · [한국어 안내](README.md) · [English](../ACTIVATION.md)

이 문서는 한국어 보조 요약입니다. 전체 설정과 동작 조건은 [영문 기준 문서](../ACTIVATION.md)를 확인하세요.

## 개요

HTTP/TCP 라우트, 인증서 항목, 전역 캐시 정책을 삭제하지 않고 활성/비활성으로 전환할 수 있습니다. 설정값은 저장되며 새 요청에 반영됩니다. 비활성 HTTP 라우트 대신 다른 활성 라우트가 매칭될 수 있고, 공유 TCP SNI 리스너는 나머지 활성 라우트를 계속 처리합니다. 기존 스트림은 유지되며 다시 활성화할 때 포트 충돌이나 인증서 오류가 있으면 이전 설정을 유지합니다.

인증서 비활성화는 현재 인스턴스의 TLS 선택만 변경합니다. 별도 ACME 발급기의 갱신이나 다른 HTTPS 인스턴스를 중지하지 않습니다. 캐시 비활성화도 정책을 보존하며 데이터 삭제를 의미하지 않습니다.
