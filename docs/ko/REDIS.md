## 개요

Redis는 검증된 TLS로 접속하고 하나의 키에서 전체 설정 revision을 원자적으로 비교·교체합니다. 큰 u64 revision도 문자열 비교로 정밀도를 보존합니다. 실제 테스트 전용 Redis의 TLS·잘못된 CA·재접속·경합과 두 게이트웨이 프로세스의 충돌·동기화·재시작을 검증했습니다. 장애 중에는 각 프로세스의 마지막 정상 설정을 유지합니다.
