## 개요

`--acme-config`로 명시적으로 활성화하며 일반 도메인은 HTTP-01, 와일드카드는 DNS-01을 사용합니다. HTTP-01은 인터넷의 80번 포트가 `--acme-http-listen`으로 도달해야 합니다. DNS 공급자는 Cloudflare 또는 인증된 HTTPS webhook을 지원합니다. 공급자 토큰은 파일에서 읽으며, 런타임 JSON 설정과 토큰 변경은 500ms 주기로 확인합니다. 별도 `hangang-acme-issuer` 프로세스의 설정은 2초 주기로 폴링합니다. ZeroSSL은 EAB KID와 HMAC 키를 함께 지정합니다.

계정과 인증서·개인 키 번들은 쓰기 가능한 영속 디렉터리에 보관합니다. 발급 실패나 잘못된 설정 교체 중에는 마지막으로 검증한 인증서를 유지합니다. 상태 API와 웹 화면에서 발급 단계·도메인·만료 시각·`tls_available`·`bundle_digest`를 확인할 수 있습니다. 여러 인스턴스를 운영할 때는 공유 설정 저장소(`--database`)로 HTTP-01 토큰을 공유하고, 계정·번들 경로를 공유 볼륨에 두어 잠금 보유자 한 곳만 발급하게 하며, 나머지 인스턴스는 5초마다 번들 파일 변경을 감지해 인증서를 새로 적재합니다([영문 다중 인스턴스 안내](../ACME.md#multiple-instances) 참고). 공유 모드에서는 저장소가 토큰 게시를 확인(최대 3회 시도)한 뒤에야 CA에 검증 준비를 알리며, 게시가 끝내 실패하면 해당 발급 시도는 오류로 중단되고 `last_error`에 이유가 남습니다. 게시된 레코드는 주문이 끝날 때까지 주기적으로 갱신되므로 검증이 늦게 도착해도 어느 인스턴스에서든 응답할 수 있습니다. 실제 운영 전 도메인·공급자·네트워크 경로에 맞춘 검증이 필요하며, 개발 검증은 소유한 테스트 CA와 컨테이너에서만 수행합니다.
