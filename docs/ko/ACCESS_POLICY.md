# HTTP 접근 모드

이 문서는 한국어 보조 요약입니다. 전체 설정과 동작 조건은 [영문 기준 문서](../ACCESS_POLICY.md)를 확인하세요.

## 개요

HTTP 라우트에 기존 동작·공개·애플리케이션 인증·게이트웨이 보호 모드를 명시합니다. 보호 모드에서는 실제 인증기를 모두 제거하는 변경을 서버가 거부하고 이전 설정을 유지합니다. 일반 Lua 변조는 계속 지원합니다. 이 단계는 인증 설정의 우발적 제거를 막는 기능이며, 사용자별 권한·mTLS·폐기·감사까지 포함한 Zero Trust 전체 구현은 아닙니다.
