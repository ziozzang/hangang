## 개요

`workload_http`는 일반 공개 HTTP/HTTPS와 별도인 클라이언트 인증서 필수 수신기를 만듭니다. 보호된 HTTP 경로는 `workload_auth`로 실제 수신기 ID와 정확한 SPIFFE URI를 허용하고, 적용 중인 `resource_policy`에서 주체와 메서드를 다시 검사합니다. 인증서가 유효하더라도 세 허용 목록 중 하나라도 불일치하면 통과하지 못합니다. 활성 수신기의 로컬 파일은 메타데이터를 500ms마다 폴링하고 전체 내용을 5초마다 검증합니다. 새 바인딩은 게시 후 검증될 때까지 대기하며 잘못되거나 변경된 클라이언트 CA·CRL은 기존 신뢰를 유지하지 않고 해당 수신기의 인증 연결과 기존 스트림을 닫습니다. 현재 인스턴스 상태는 `GET /v1/status`와 구성 화면에서 확인합니다. 이 기능은 플릿 전체 자료 배포, 영구 감사, 백엔드 직접 접근 차단까지 제공하지 않습니다.
