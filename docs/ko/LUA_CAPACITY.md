# Lua 처리 용량

이 문서는 한국어 보조 요약입니다. 전체 설정과 동작 조건은 [영문 기준 문서](../LUA_CAPACITY.md)를 확인하세요.

## 개요

Lua 워커가 모두 사용 중이거나 복구 중일 때의 요청 거부를 스크립트 오류와 구분합니다. 전용 상태·Prometheus 지표와 영어/한국어 UI를 제공하지만, 기존 전체 정책 오류에도 포함되므로 두 값을 합산하면 안 됩니다. 대기열이나 실행 용량을 늘리는 변경은 아니며, 요청은 정책을 건너뛰지 않고 503으로 거부됩니다.
