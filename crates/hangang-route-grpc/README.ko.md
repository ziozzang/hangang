# Hangang Route gRPC

[English](README.md) · [한강](../../README.ko.md)

요청별 네이티브 라우팅 관측의 독립 Rust 생성 계약입니다. 정책·프로바이더·DB·권한·
자격 투영 로직을 소유하지 않습니다. 기존 원천 계약처럼 빌드에 protoc가 필요합니다.
Rust에서는 hangang_route_grpc::v1을 사용하며 각 소비자에 정적으로 링크합니다.

RouteOwnership/Observe는 32바이트 네이티브 참조·준비된 요청 digest·최종 절대
upstream URI의 UTF-8 표시값에 대한 SHA-256을 받습니다. 요청 ID 범위는
1–9,007,199,254,740,991입니다. 대상 해시는 별도 경로/본문 계약과 달리 scheme과
authority도 포함합니다. 서버가 포착 시 두 digest를 계산하므로 조회 시 본문을
재해시하지 않습니다.

서버 라이브러리는 실제 조회 전에 mTLS와 별도 Bearer 자격을 요구하고 중복·누락·
잘못된 자격을 거부합니다. 자격은 환경 변수 참조로 제한하고 길이·표시 가능 ASCII를
검사하며 제공된 다른 역할 자격과의 충돌을 거부합니다. 요청 512바이트·응답
1,024바이트와 공용 런타임의 연결/stream/header/deadline 제한을 적용합니다.

응답의 route·서비스·audience·자원·행위·packed IP는 보존된 실제 소유자에서
가져옵니다. 알 수 없거나 취소/만료된 참조·digest 변경·스냅샷 교체는 소유자 정보
없이 거부합니다. 공개 설정 리비전은 진단값이며 소유자 incarnation이 아닙니다.
잔여 1–1,000ms는 시점 관측입니다. 클라이언트는 교환 시간을 반영해야 하며
성공 응답은 권한 허가나 분산 lease가 아닙니다.

현재 한강 소스는 서버 라이브러리와 실제 소켓 검증을 제공합니다. 게이트웨이
시작/감독 인계·품계로 참조 전달·원격 판정 클라이언트·서명 권한·투영/replay·
K8s 릴리스 적용은 계속 연결해야 합니다. 호출자 URL이나 애플리케이션의 등급/
허용 주장을 실제 소유자 상태로 받아서는 안 됩니다.
